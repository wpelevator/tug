'@wpelevator/tug': minor
---

Node IDs are now generated, immutable and never reused: a node has a random `node_...` ID beside its chosen name, certificates name the ID, and a name freed by `node-remove` gets a new ID, so certificates issued for the removed node can never authenticate a node created later with the same name (even with the same key). Enrollment credentials reserve their node ID when minted, and `status` includes each report's node name. `tug doctor` now reports the control CA, server and every node certificate's expiry (warning when renewal is overdue, failing when expired) and each online node's observed clock skew; offline nodes report an unknown skew instead of a stale value. Agents send their clock with status reports. The control-side Compose check is gone from `doctor`. `x-tug.placement.global` is removed in favor of `x-tug.global` and is rejected with a pointer to it. The runtime and fake-VPS images no longer ship the Compose plugin (nodes use the Docker Engine API), and the image smoke test now also verifies certificate issuance and the undici transport on Debian and Alpine. Help and error text, audit messages and the documentation now use operator credential, control plane, node and agent consistently, and no longer describe bearer tokens, plain HTTP, port 8080, `/healthz` or Compose on nodes.
