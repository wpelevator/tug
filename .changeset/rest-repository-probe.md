Decide whether a backup repository is missing from restic's exit code 10 instead of its message, in control and on nodes. Control's own backup now creates the `_control` repository on a REST server, and a mistyped S3 bucket fails instead of being created. The protection against creating a mistyped bucket applies once each node's agent is upgraded, because nodes run the check themselves. Automatic repository creation now requires restic 0.17 or newer, which matters only with a custom `TUG_RESTIC_IMAGE`; the error names a restic older than 0.17. `backup.check` no longer initializes a repository, and a wrong repository password is named in the error. `sftp:` and `rclone:` destinations were accepted but never worked, so rejecting them with the reason is a fix. `tug backup password` and the repository password endpoint work before a project is deployed and say whether it has been, and `tug backup run` explains that a project that was never deployed has no backup targets yet.
